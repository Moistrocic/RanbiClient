# Auto fish 区域与自动购买鱼饵实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Ranbi 设置菜单 "Auto attack" 区域标题改为 "Auto fish"（内容不变），并新增"自动购买鱼饵"功能：按可配置间隔（10–60s 默认 30s）模糊匹配服务器投票选项中的"购买鱼饵"并触发该投票（等效双击）。

**Architecture:** 配置变量驱动（`rc_auto_buy_bait` 开关 + `rc_auto_buy_bait_interval` 秒间隔），`CRanbiClient::OnUpdate` 中定时遍历 `GameClient()->m_Voting.FirstOption()` 链表，`str_find_nocase` 匹配"购买鱼饵"后调用 `m_Voting.CallvoteOption(OptionId, "", false)`（即"发起投票"界面双击选项链路的最终动作）。UI 在 Ranbi Settings tab 的 Auto fish 区块内新增控件。

**Tech Stack:** C++ / DDNet 客户端组件框架 / CMake+Ninja 构建（gcc 14.2，`-Werror`）

- [ ] **Step 2: 实现定时检查逻辑**

`ranbi_client.cpp` `OnUpdate()` 中，在现有 Auto attack 注入逻辑的 `else` 分支（开关关闭复位）之后、函数返回前插入：

```cpp
	// RANBICLIENT m_RcAutoBuyBait
	if(g_Config.m_RcAutoBuyBait)
	{
		const int Dummy = g_Config.m_ClDummy;
		const int LocalId = GameClient()->m_aLocalIds[Dummy];
		if(LocalId >= 0 && LocalId < MAX_CLIENTS && GameClient()->m_aClients[LocalId].m_Active)
		{
			const int64_t Now = time_get();
			if(m_BuyBaitNextCheckTime == 0)
				m_BuyBaitNextCheckTime = Now;
			if(Now >= m_BuyBaitNextCheckTime)
			{
				int OptionId = 0;
				for(const CVoteOptionClient *pOption = GameClient()->m_Voting.FirstOption(); pOption; pOption = pOption->m_pNext, OptionId++)
				{
					if(str_find_nocase(pOption->m_aDescription, "购买鱼饵"))
					{
						GameClient()->m_Voting.CallvoteOption(OptionId, "", false);
						break;
					}
				}
				m_BuyBaitNextCheckTime = Now + time_freq() * g_Config.m_RcAutoBuyBaitInterval;
			}
		}
		else
		{
			m_BuyBaitNextCheckTime = 0;
		}
	}
	else
	{
		m_BuyBaitNextCheckTime = 0;
	}
```

要点：
- 间隔单位为秒：`time_freq() * interval`（interval 10–60）
- 首次开启时 `m_BuyBaitNextCheckTime == 0` 初始化为 `Now`，不会开启瞬间立即触发
- 选项链表为空时循环自然跳过，无副作用
- 匹配成功即 `break`，同间隔内只触发一次
- 开关关闭或角色无效时复位定时器，重新开启从当前时刻起算
